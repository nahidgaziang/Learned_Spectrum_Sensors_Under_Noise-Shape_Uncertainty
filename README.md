# Learned Spectrum Sensors Under Noise-Shape Uncertainty: An Invariant-Detection Analysis

Code, configurations, run records and supplementary material for the manuscript
*"Learned Spectrum Sensors Under Noise-Shape Uncertainty: An Invariant-Detection Analysis"* by Nahid Gazi (Department of Computer Science and Engineering, Shahjalal University of Science and
Technology, Sylhet, Bangladesh).

## What the study does
Deep spectrum sensors are usually trained on simulated modulated signals against white noise, with every input window
normalised to unit power. The study tests which statistic such sensors compute and what limit follows from it:

- a **surrogate test**: trained detectors are scored on Gaussian surrogates that share the signal's power spectral
  density (PSD) but no other structure;
- an **LMPI replay**: the locally most powerful invariant (LMPI) test, with the training PSD as template, is evaluated on
  the exact test windows of the trained detectors;
- the **noise-shape SNR wall** of scale-invariant detection, in closed form for any signal spectrum, checked by wall tests
  with the extremal noise pair;
- an **escape law** for the cyclic-autocorrelation detector (noncentral chi-square), checked without a fitted parameter;
- measurements on recorded RTL-SDR noise of two receivers and on over-the-air signals (two public datasets).

## Repository layout
| Path | Content |
|---|---|
| `CODE/` | simulator (`sim.py`), detectors (`detectors.py`), training/evaluation (`run.py`, `evaluate.py`), experiment scripts, figure/table/number generators, verification scripts |
| `CONFIGS/` | experiment queues (`queue_*.json`) for `run.py` |
| `RESULTS/runs/` | one JSON record per training/evaluation run (configuration, code version, training history, runtime, metrics) |
| `RESULTS/scores/` | raw test scores of every run (`.npz`) |
| `RESULTS/*.json`, `*.csv` | outputs of the experiment and analysis scripts |
| `TABLES/`, `FIGURES/` | generated tables (LaTeX/CSV) and figures (PDF, PNG) |
| `MANUSCRIPT/numbers.tex` | every number used in the manuscript, as LaTeX macros generated by `CODE/paper_numbers.py` |
| `SUPPLEMENTARY_MATERIAL.pdf` | supplementary material (numerical checks of the theory, implementation details, extended tables) |
| `REPRODUCIBILITY.md` | environment, data, full command list, seeds, mapping from paper items to code |

## Quick start
```
pip install -r requirements.txt
python reproduce.py --verify      # claim checks and independent recomputation from the stored records
python reproduce.py --analysis    # regenerate tables, figures and MANUSCRIPT/numbers.tex from the stored records
```
Both steps run on a CPU in minutes and need no downloads. Full re-training and the real-data experiments are described
in `REPRODUCIBILITY.md` (about 9 GPU-hours on a 6 GB laptop GPU).

## Data
- Simulated data are generated on the fly by `CODE/sim.py`; nothing has to be downloaded for the main experiments.
- Recorded noise and real signals come from two public Hugging Face datasets and are **not redistributed** here:
  `ishisan28/rf-signal-dataset` (no licence stated; used for evaluation only) and `TrevTron/rtl-ml-dataset` (MIT).
  Download them with `CODE/fetch_real_noise.py` and `CODE/fetch_real_signals.py`.
- Model checkpoints (125 MB) are not included; `run.py` regenerates them from the queues in `CONFIGS/`.
